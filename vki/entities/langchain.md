# LangChain

## Type
Framework / Tool

## Summary
LangChain 是最流行的 LLM 应用开发框架，提供 Models、Prompts、Parsers、Memory、Chains、Agents 等模块化组件。创始人 Harrison Chase。生态包含 LangGraph（Agent 编排）、LangSmith（追踪）、LangServe（部署）。

## Key Facts
- 核心组件：Models, Prompts, Parsers, Memory, Chains, Agents
- LCEL (LangChain Expression Language)：Runnable 协议，pipe 操作符
- Memory 类型：Buffer, Window, Token, Summary, Vector, Entity
- Chain 类型：LLMChain, SequentialChain, RouterChain
- QA 方法：Stuff, Map_Reduce, Refine, Map_Rerank
- 生态系统：LangGraph, LangSmith, LangServe, LangChain Hub
