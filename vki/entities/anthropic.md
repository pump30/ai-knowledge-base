# Anthropic

## Type
Organization

## Summary
Anthropic 是 Claude 系列模型的开发公司，在 AI Agent 工具链方面推出了 MCP、Claude Code、Skills 等创新。强调安全和可控的 AI 开发理念。

## Key Facts
- 核心产品：Claude 模型系列（Opus, Sonnet, Haiku）
- 开发者工具：Claude Code, Claude API, Agent SDK
- 开放标准：MCP (Model Context Protocol)
- 创新概念：Skills 系统, Progressive Disclosure
- 教育合作：与 DeepLearning.AI 合作课程（MCP、Claude Code、Agent Skills）
